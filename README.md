# 🚀 BD AIO Python Fundamentals Assignments

Welcome to the **BD AIO Python Fundamentals Assignments** repository!

This repository is created for our community members to share Python assignment solutions, learn from different approaches, receive feedback, and improve together.

> **Our goal is not to copy code. Our goal is to learn together.**

---

## 🎯 Mission

Many of us solve an assignment, understand it, and then move on.

After a few weeks, we often forget what we learned. Another common problem is that we usually code alone, so no one reviews our code and we keep making the same mistakes.

This repository aims to solve that problem.

After every assignment:

- Solve the problem by yourself.
- Upload your solution to GitHub.
- Share your repository with the community.
- Review other people's solutions.
- Learn new approaches.
- Improve together.
